# From adjacency list to adjacency matrix

[basecamp](https://eolymp.com/en/problems/3982)

A simple directed graph is given as an adjacency list. Output its representation as an adjacency matrix.

# InputFile
The first line contains the number of vertices n (1≤n≤100). Each of the following n lines describes the outgoing edges from the i-th vertex. Each line begins with the number of outgoing edges, followed by the numbers of the vertices those edges point to. Vertices are numbered from 1 to n.

# OutputFile
Output the adjacency matrix of the directed graph.


# Examples

Input #1
```
3
2 2 3
0
1 2
```
Answer #1
```
0 1 1
0 0 0
0 1 0
```
