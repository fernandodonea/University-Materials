Creeare Proiect MVC - MacOS

1. Creare un folder nou si intra in el
```bash
mkdir MyMvApp && cd MyMvApp
```
2. Creeaza aplicatia mcv
```bash
dotnet new mcv
```
3. Ruleaza aplicatia
```bash
dotnet run
```
4. Deschide in VsCode
```bash
code .
```
5. Adauga controller rapid
```bash
dotnet new controller -name StudentsController -actions
```
